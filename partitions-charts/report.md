## 1. Главный вывод перед таблицей: куда реально смотрит покупатель

Проверка выдачи по запросам «межкомнатные перегородки купить раздвижные на заказ
Москва» (поисковый API, профиль ближе к Google; выдачу Яндекса из РФ доснять
вручную — п. 11 раздела 6) показала: **топ-10 занят сайтами производителей, а
не агрегаторами** — Loftcase, MosDvery, UNION, Raumplus, Терем, Estet, RIAL,
Rondicom и т.п. [B]. Маркетплейсы в органике по «перегородкам на заказ» почти не видны:
продукт заказной, габаритный, с замером — классическая витрина «готового товара»
работает хуже.

Следствия для стратегии:
1. **Приоритет №1 — каналы, где возможен диалог и заказ по размерам** (Авито,
   нишевые мебельные маркетплейсы с моделью «под заказ», собственный сайт + SEO).
2. Универсальные маркетплейсы (Ozon/WB/ЯМ) — для **готовых типовых решений**
   (стандартные полотна/комплекты), не для заказных конструкций.
3. «Рейтинги производителей перегородок» в выдаче — в основном редакционные или
   SEO-статьи магазинов (expertology.ru, goodoors.ru, DTF-топы); попадание туда —
   это PR/переговоры, а не публичный прайс.

## 3. Карточки площадок (детали и источники)

### 3.1 Авито для бизнеса — приоритет №1 для «на заказ»
- **Формат:** объявления + витрина компании; в «Мебели и интерьере» бесплатный
  лимит 3–10 объявлений в зависимости от подкатегории [B].
- **Цены:** тарифы для бизнеса от ~1 500 до 50 000+ ₽/мес [B]; минимальный аванс
  на просмотры 600 ₽ [B]; реалистичный бюджет малого бизнеса с продвижением —
  30 000–60 000 ₽/мес, в Москве инструменты в 2–3 раза дороже регионов [B].
- **Сроки:** регистрация и модерация объявлений — 1–3 дня [B].
- **Проверка:** разовая модерация каждого объявления; далее рейтинг по отзывам
  (постоянный цикл).
- **Требования:** ИП/ООО (для кабинета «для бизнеса»), качественные фото,
  сертификаты не нужны. Формат «мебель по индивидуальным размерам» прямо
  поддерживается — покупатель ожидает диалога, что идеально для перегородок.
- **Почему нам:** SERP-логика «на заказ» + возможность вести клиента в замер.

### 3.2 Roomsee — дизайнерская мебель, модель «под заказ»
- 126 500+ товаров от 194 фабрик [A — сниппет roomsee.ru]; комиссия ~10% [B].
- Вход: анкета на seller.roomsee.ru → договор-оферта в ЛК → загрузка уставных
  документов → модерация [A]. Продавец: ИП/ООО/самозанятый [B].
- Площадка сама может делать карточки и рекламу; работает с мебелью под заказ
  (совместная проработка дизайна с покупателем) и организует сборку по всей РФ [B].
- **Почему нам:** редкое сочетание — дизайнерский сегмент + заказная модель +
  комиссия ниже универсальных МП. Срок выхода не публикуется [C — уточнить].

### 3.3 INMYROOM + INMYROOM PRO — выход на дизайнеров
- Без абонплаты и платы за размещение [A — partners-inmyroom.ru]; комиссия
  зависит от категории [A], ориентиры из обзоров: ~15%, при передаче логистики
  площадке — до ~30% [B/C].
- Требования: не менее 50 артикулов [A]; два договора — на обслуживание и на
  доставку через СДЭК [A]; выплаты: «в наличии» — 2 раза/мес, «под заказ» —
  1 раз/мес [A].
- INMYROOM PRO — отдельный маркетплейс для дизайнеров интерьера (130 000+
  позиций, агентские до 15%, персональный менеджер) [A — сниппет pro.inmyroom.ru].
- **Риск:** логистика СДЭК плохо совместима с крупногабаритными стеклянными
  конструкциями — обсуждать индивидуальную схему доставки [C — уточнить у
  partners@inmyroom.ru].
- **Почему нам:** дизайнеры — ключевой канал продаж дизайнерских перегородок;
  присутствие в INMYROOM даёт и медиа-обвязку (их «Топ-5 раздвижных перегородок»
  — редакционный формат, куда реально попасть, будучи поставщиком платформы).

### 3.4 Лемана ПРО (экс-Леруа Мерлен) — стратегический DIY-канал
