# 2026-07-03 — Анализ тарифов vc.ru для блога компании

## Задача и итог
Разобраться в платных подписках vc.ru для компаний и дать рекомендацию с цифрами
для сценария «2–4 статьи/мес со ссылками на сайт». Отчёт:
`vc-ru-analysis/report.md`. Оценка hard-critic: **93/100 (A), к публикации**.

## Какой микс сработал
1. WebSearch (7 запросов) — vc.ru и большинство агентских сайтов блокируются
   на fetch (403 через прокси), но поисковые сниппеты отдают содержимое страниц
   vc.ru, включая пользовательское соглашение подписок с точными ценами.
2. Точечный запрос по номиналам цен ("39 900" OR "69 900" + pro-agreement) —
   лучший приём: вытащил полную сетку 1/3/6/12 мес из соглашения.
3. Python-скрипт для сверки всей арифметики отчёта (20 расчётов) перед критикой.
4. hard-critic с адаптированной рубрикой под аналитический отчёт.

## Ключевые факты (для переиспользования)
- Pro: 39 900 ₽/мес; год 394 800 ₽ (32 900/мес). Pro Max: 69 900 ₽/мес; год
  682 800 ₽ (56 900/мес). Источник: vc.ru/pro-agreement, ред. ~03.04.2026.
- Без подписки: 1 публикация/мес, статьи скрыты из лент.
- nofollow/dofollow внешних ссылок на vc.ru подтвердить из выдачи НЕ удалось —
  проверять вручную по исходному коду статьи.

## Что положить в базу знаний
- Скриншоты/выгрузку актуальных vc.ru/ads и vc.ru/pro при ручной проверке.
- Результат ручной проверки rel-атрибута внешних ссылок (критично для SEO-решений).

## Бэклог апгрейдов v2
1. После ручной проверки nofollow — пересчитать ценность канала: трафик+бренд
   vs линкбилдинг.
2. Добавить сравнение с альтернативами (Хабр, Дзен, Sostav, отраслевые СМИ)
   по цене за статью и трафику.
3. Через 1-3 мес теста Pro — посчитать фактический CAC из Метрики и обновить
   рекомендацию (переход на годовую / отказ).
4. Мониторить цены: vc.ru меняет их динамически (29 900 → 49 900 → 39 900 за 3 года).
