# Журнал решений и апгрейдов

Здесь Ричард фиксирует каждую завершённую задачу. Это долговременная память
системы: каждое решение делает следующее лучше. **Без записи сюда работа не
считается завершённой.**

## Формат файла
Имя: `YYYY-MM-DD-<slug>.md` (напр. `2026-07-17-email-welcome.md`).

Содержимое:
- **Задача** — что решали, для кого, критерии приёмки.
- **Итоговая оценка** — балл по рубрике `hard-critic` и грейд.
- **Микс** — какие скиллы/агенты, в каком порядке, и почему сработало.
- **В базу знаний** — что добавить в `knowledge-base/`, чтобы следующий раз был сильнее.
- **Бэклог апгрейдов v2** — конкретные идеи, как поднять результат ещё выше.

- …
