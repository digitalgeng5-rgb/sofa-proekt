# Журнал решений и бэклог апгрейдов

Ричард ведёт здесь историю решённых задач. Каждое решение = один файл
`YYYY-MM-DD-<короткое-имя>.md`. Это память проекта: каждая новая задача опирается
на предыдущие и делает результат сильнее.

## Шаблон записи

```markdown
# <Задача> — <дата>

## Итог
- Оценка: NN/100 (грейд) — прошли планку 11/10? да/нет
- Ссылки на артефакты: <файлы/PR>

## Сработавший микс
1. <инструмент> — зачем — что дал
2. …

## Что использовали из базы знаний
- …

## Чего не хватило в базе знаний (положить, чтобы было сильнее)
- …

## Бэклог апгрейдов (v2)
- [ ] …
- [ ] …
```
