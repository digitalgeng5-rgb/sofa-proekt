# 2026-07-03 — Скан чартов/каталогов/маркетплейсов для перегородок GENGROUP

## Задача и итог
Просканировать площадки (маркетплейсы, B2B-каталоги, дизайн-агрегаторы,
редакционные рейтинги) для размещения дизайнерских перегородок GenGlass:
цены входа, сроки, модерация, требования. Отчёт: `partitions-charts/report.md`.
Оценка hard-critic: **93/100 (A), к публикации** (после закрытия 1 блокера:
завышенная пометка достоверности на SERP-выводе).

## Какой микс сработал
1. WebSearch батчами по 3 запроса (8 батчей, ~24 запроса) — почти все данные
   из сниппетов; WebFetch на RU-сайты стабильно 403 (yandex support, pulscen,
   wb-calculator, atlantmzs) — не тратить на них попытки.
2. SERP-анализ как рамка приоритизации: по «перегородки на заказ» в топе
   производители, не агрегаторы → приоритет каналам с диалогом (Авито, нишевые
   МП «под заказ»), универсальные МП — вторая волна.
3. hard-critic с адаптированной рубрикой (полнота брифа + пометки [A]/[B]/[C]
   вместо SEO/CTA) — поймал главный риск: [A] на неподтверждённом выводе.

## Ключевые факты (переиспользовать)
- Roomsee: комиссия ~10%, дизайнерская мебель, модель «под заказ», 194 фабрики.
- INMYROOM: без абонплаты, ~15% (до ~30% с их логистикой), порог 50 SKU,
  доставка через СДЭК (риск для стеклянного крупногабарита).
- Лемана ПРО: 0% комиссии, вход = бизнес >1 года + статус изготовителя +
  контрольная закупка; акция до 31.08.2026 (доставка бесплатно до 5 мес).
- ВсеИнструменты: 0% комиссии, оптовая модель, ответ на анкету до 5 дней.
- Ozon мебель ~19% FBS; WB гарантийный взнос 5/10/30 тыс. ₽ — противоречие [C].
- Перегородки/межкомнатные двери НЕ подлежат обязательной сертификации —
  достаточно отказного письма (бессрочное).
- «Базар мебели» как площадка не существует/не находится; «Дизайн Молл» — офлайн-ТЦ.
