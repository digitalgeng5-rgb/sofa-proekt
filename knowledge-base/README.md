# База знаний

Это каноническое место для базы знаний, которую проверяет агент-оркестратор
**Ричард** (`.claude/agents/richard.md`) перед решением любой задачи.

## Что сюда класть
Складывай всё, что делает решения точнее и «на бренд»:
- **Бренд и стиль:** tone of voice, гайдлайны, запреты, примеры «как надо»/«как нельзя».
- **Факты о компании/продукте:** услуги, характеристики, цифры, гарантии, контакты.
- **Материалы и референсы:** каталоги, прошлые рассылки, лендинги, посты.
- **Аудитория:** сегменты, боли, возражения, сценарии.
- **Данные:** ключевые слова, результаты аналитики, отчёты.

Форматы любые: `.md`, `.txt`, `.html`, `.pdf`, изображения. Желательно давать файлам
понятные имена. По возможности дублируй суть важных PDF/картинок в `.md` — так
Ричард и скиллы используют это надёжнее.

## Структура
```
knowledge-base/
├── README.md            ← этот файл
├── (ваши документы)     ← сюда загружаете базу знаний
└── solutions/           ← журнал решений и бэклог апгрейдов (ведёт Ричард)
```

## Как пользоваться
1. Загрузите материалы в `knowledge-base/`.
2. Поставьте задачу Ричарду (агент `richard`).
3. Он изучит базу, соберёт идеальный микс агентов+скиллов, доведёт до 11/10 и
   запишет журнал в `knowledge-base/solutions/` для апгрейда в будущем.
