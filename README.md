# sofa-proekt

Рабочее пространство Claude Code для **контент-маркетинга**: агент-оркестратор
«Ричард», кастомный скилл «Жёсткий критик» и стек плагинов (humanizer, SEO/GEO,
оценка качества, дизайн).

## Быстрый старт
1. Открой репозиторий в Claude Code и подтверди доверие к папке — появится
   предложение установить плагины из [`.claude/settings.json`](.claude/settings.json).
2. Подробности стека и ручная установка — в [`SKILLS.md`](SKILLS.md).
3. Контекст проекта и роль «Ричарда» — в [`CLAUDE.md`](CLAUDE.md).

## Структура
- [`CLAUDE.md`](CLAUDE.md) — память и контекст проекта (читается автоматически).
- [`SKILLS.md`](SKILLS.md) — что установлено и как пользоваться.
- `.claude/agents/richard.md` — агент-оркестратор «Ричард».
- `.claude/skills/hard-critic/` — скилл «Жёсткий критик» + бренд-правила.
- `.claude/settings.json` — подключённые плагины.
- `knowledge-base/` — база знаний и журнал решений.
